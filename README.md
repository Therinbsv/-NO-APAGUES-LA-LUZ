# NO APAGUES LA LUZ

Prototipo inicial de la pantalla de inicio de un videojuego 2D creado con JavaScript, Phaser 3 y Vite.

Por ahora, el proyecto muestra un fondo, el titulo y botones de muestra. Los botones no tienen acciones. No se carga audio ni se inicia el juego, y todavia no se muestran personajes.

## Ejecutar

Requiere Node.js.

```bash
npm install
npm run dev
npm run build
```

La pantalla se renderiza con Phaser. El fondo se genera localmente en `src/assets/TextureFactory.js`; no se cargan recursos de audio ni escenas de juego durante este prototipo.
